Depth First Search (DFS)

An interactive website to learn how Depth First Search visits the vertices of a graph.

1. Introduction

Depth First Search (DFS) is a graph traversal algorithm. It starts at one vertex and visits an unvisited neighbour, going as deep as possible before backtracking.

Applications include graph traversal, path exploration, cycle detection, and finding connected components.

Working Steps

  1. Select a starting vertex.
  2. Mark it as visited.
  3. Visit an unvisited neighbour recursively.
  4. Backtrack when there are no unvisited neighbours.

3. Pseudocode

DFS(node):
    mark node as visited
    print node
    for each neighbour of node:
        if neighbour is not visited:
            DFS(neighbour)

A visited set prevents repeated visits and infinite loops in cyclic graphs.

4. Complexity Analysis

Time: O(V + E)Space: O(V)

V is the number of vertices and E is the number of edges. With an adjacency list, DFS visits vertices and checks edges efficiently.
